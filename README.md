# 电商运营与智能问数中台系统 (E-Commerce Ops & AI Copilot Platform)

面向企业级电商业务的高可用、高可解释性**运营管理中台与 Text2SQL 智能体一体化系统**。

基于 **Java 21** 与 **Spring Boot 3** 开发，采用**敏捷软件开发过程（Agile / Scrum）**构建。系统同时具备**传统业务管理中台（商品/订单 CRUD、分页多维检索）**与**大语言模型驱动的 Text2SQL 智能体（加权外键图规划、业务口径注入、AST 安全沙箱防护、ECharts 动态图表渲染）**。

---

## 核心系统特性

1. **电商业务管理中台 (CRUD Domain)**
   - **商品全生命周期管理**：支持商品列表分页筛选、按类目与关键字模糊检索、参数详情查看、新增、编辑单价与下架。
   - **订单中心与状态流转**：支持订单物流进度追踪、买家信息联动与明细汇总。
   - **数仓业务指标字典**：可视化管理与查看 GMV、客单价、复购率等标准业务口径。
2. **AI Copilot 智能问数中枢 (Text2SQL Agent Domain)**
   - **自然语言即席查数**：业务人员无需编写复杂 SQL，输入自然语言即可秒级生成标准 SQL 并执行。
   - **ECharts 智能图表联动**：聚合统计数据自动识别并绘制为折线图、柱状图或饼图，一键导出。
   - **生产级三层安全防御**：基于 JSqlParser 的 AST 列级白名单校验 + 数据库只读账号沙箱（`text2sql_ro`）物理级隔离 + 10s 执行超时熔断。

## 快速启动

### 1. 环境依赖
- JDK 21+
- Maven 3.9+
- PostgreSQL 16 (带 Olist 电商数据集)

### 2. 编译与启动
```bash
# 1. 编译与单元测试
mvn clean test

# 2. 启动服务（默认端口 8080）
mvn spring-boot:run
```
访问中台主界面：`http://localhost:8080`
