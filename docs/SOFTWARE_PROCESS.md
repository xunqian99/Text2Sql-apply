# 《电商运营与智能问数中台系统》软件过程与需求规格说明书

## 1. 软件工程过程模型（Agile / Scrum）

本项目开发过程严格遵循**敏捷开发迭代模型（Agile / Scrum）**。将系统目标拆解为 4 个清晰的迭代冲刺（Sprint），每个 Sprint 均经历「需求分析 ➔ 方案设计 ➔ 编码实现 ➔ 自动化测试 ➔ 评审回顾」的完整闭环，确保交付物在每个阶段结束时均处于**高可用可运行状态**。

---

## 2. Sprint 迭代过程日志

### 迭代一：Sprint 1（系统脚手架与商品管理 CRUD）
- **目标**：搭建工程底座，验证 Maven 依赖与数据库驱动，实现商品业务域数据访问与管理。
- **用户故事**：运营人员需要按品类、关键词分页检索商品，查看商品基础属性并进行维护。
- **交付成果**：
  - 构建标准 Maven 工程与 Spring Boot 3.5.16 依赖树；
  - 实现 `ProductController`、`ProductService`、`ProductRepository`；
  - 交付 `ProductServiceTest`（3 项单测，通过率 100%）；
  - Git Commit: `cec4c2a`。

### 迭代二：Sprint 2（Text2SQL AI 智能体核心引擎集成）
- **目标**：接入大模型协议，建立加权外键图规划、指标口径注入与 AST 安全防护流水线。
- **用户故事**：运营人员通过自然语言提出统计分析问题，智能体准确理解意图并生成安全合规的只读 SQL。
- **交付成果**：
  - 编排引擎 `Text2SqlOrchestrator` 与会话上下文压缩器；
  - JSqlParser 严格 AST 语法树解析与列级只读白名单校验；
  - 交付 251 项核心单元测试（通过率 100%）；
  - Git Commit: `feat(sprint-2)`。

### 迭代三：Sprint 3（订单中心、指标字典与一体化 UI）
- **目标**：补齐订单域业务与业务口径字典，研发现代化管理中台前端并集成 ECharts 5。
- **用户故事**：用户在统一中台界面中进行商品/订单管理，并可随时呼出 AI 智能问数助手，自动将查询结果绘制为统计图表。
- **交付成果**：
  - 实现 `OrderController` 与 `MetricDictionaryController`；
  - 单页现代化前端 UI（`static/index.html`），内置侧边栏、表格分页、Copilot 抽屉与 ECharts 动态渲染；
  - 交付全套测试（253 项单测，通过率 100%）；
  - Git Commit: `56dcb2b`。

### 迭代四：Sprint 4（构建部署包与答辩材料归档）
- **目标**：构建生产级部署包，整理软件工程说明书、PPT 框架与录屏演练方案。
- **交付成果**：
  - 执行 `mvn clean package` 产出最终可执行部署包：`target/ecommerce-admin-agent-1.0.0.jar` (38.7 MB)；
  - 交付全套工程文档。
