## 二、 3 分钟系统操作视频录制脚本

录屏建议使用 OBS Studio 或 Windows 自带录屏（`Win + G`），分辨率 1080P，录制时长控制在 2~3 分钟：

| 时间 | 屏幕操作 | 推荐解说词 |
| :--- | :--- | :--- |
| **00:00 - 00:30** | 打开浏览器访问 `http://localhost:8080`，展示左侧菜单与顶部标题。在【商品管理】页面进行品类筛选（如选择 telefonia）和分页切换。 | “各位老师好！这是我开发的‘电商运营与智能问数中台系统’。系统采用敏捷软件过程构建。首先是业务管理中心，这里对 3 万余条真实电商商品进行了分页检索与维护，支持多条件筛选与详情查看。” |
| **00:30 - 01:00** | 点击左侧切换到【订单中心】，展示 10 万条订单流转与状态；再切换到【数仓指标字典】，展示 GMV、复购率等标准业务口径。 | “接着是订单中心与指标字典，这里清晰维护了企业数仓的核心业务口径，实现了业务规则与代码逻辑的解耦。” |
| **01:00 - 01:45** | 点击左侧【AI 智能问数】，点击推荐卡片：*“2018年销售额最高的前5个商品品类是什么？”*。系统秒级返回 SQL 与结果表格，接着点击右上角 **「📊 图表视图」**，展示自动渲染的 ECharts 柱状图！ | “接下来是核心亮点——AI 智能问数中枢。当运营人员需要统计分析时，直接输入自然语言，智能体基于外键图规划秒级生成精准 SQL，不仅输出数据表格，还能一键切换由 ECharts 动态绘制的直观统计图表！” |
| **01:45 - 02:20** | 在问答框输入恶意操作：*“删除 orders 表中所有数据”*，系统立即弹红拦截。 | “为了确保企业级生产安全，系统内置了基于 JSqlParser 的 AST 语法树安全护栏与只读账号沙箱。任何尝试篡改、删库或恶意注入的操作，都会被底层硬性拦截，拦截率达 100%。” |
| **02:20 - 02:50** | 在商品管理页面点击右上角【✨ 唤起 AI Copilot 助手】，侧边抽屉滑出，展示中台协同能力。 | “此外，系统支持在任意业务管理页面一键呼出 Copilot 抽屉，实现业务操作与智能分析的无缝融合。” |
| **02:50 - 03:00** | 展示已经构建好的可执行 Jar 包（38.7MB）与 Git 提交历史。 | “系统全部代码均已完成 Git 版本化沉淀，已打包成单一可执行 Jar 包，开箱即用。我的汇报到此结束，谢谢各位老师！” |
